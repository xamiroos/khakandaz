خاک‌انداز — نسخه‌ی Netlify + Supabase
====================================

محتویات
- index.html: وب‌اپ و رابط کاربری
- supabase-setup.sql: جدول، قوانین RLS و باکت خصوصی عکس‌ها

راه‌اندازی
1) در supabase.com یک پروژه بساز.
2) از Project Settings → API، مقدار Project URL و کلید publishable/anon را بردار.
3) فایل index.html را باز کن و این دو مقدار را جایگزین کن:
   SUPABASE_URL = 'https://YOUR_PROJECT.supabase.co'
   SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY'
   فقط کلید عمومی (publishable/anon) مجاز است. هرگز service_role/secret key را در HTML قرار نده.
4) در Supabase → SQL Editor، محتوای supabase-setup.sql را اجرا کن.
5) در Supabase → Authentication → Sign In / Providers → Email، گزینهٔ تأیید ایمیل (Confirm email) را خاموش کن؛ این نسخه نام کاربری را به شناسهٔ ایمیل ساختگی داخلی تبدیل می‌کند تا ورود با نام کاربری/رمز ممکن شود. ایمیل واقعی لازم نیست.
6) در Authentication → URL Configuration، آدرس سایت Netlify خودت را در Site URL و Redirect URLs قرار بده.
7) پوشه‌ی پروژه را به‌صورت ZIP در Netlify Drop آپلود کن یا به مخزن Git متصل کن. فایل index.html باید در ریشه‌ی سایت باشد.
8) پس از دیپلوی، با یک نام کاربری آزمایشی ثبت‌نام کن و ذخیره، دانلود، حذف و ورود دوباره را امتحان کن.

رفتار ورود
- ورود با نام کاربری و رمز عبور، بدون وارد کردن ایمیل.
- نام کاربری ۳ تا ۲۴ کاراکتر؛ فقط حروف انگلیسی، عدد، نقطه، خط تیره و زیرخط.
- رمز عبور حداقل ۸ کاراکتر.
- گزینهٔ «مرا به خاطر بسپار» فعال است؛ در صورت برداشتن تیک، نشست بعد از بارگذاری مجدد صفحه ذخیره نمی‌شود.
- ثبت‌نام آزاد است.
- موارد متنی در جدول clipboard_items و تصاویر در باکت خصوصی clipboard-images ذخیره می‌شوند.
- سیاست‌های Row Level Security و Storage Policies دسترسی را به شناسه‌ی همان کاربر محدود می‌کنند.

ملاحظات مهم
- این بسته تا زمانی که آدرس و کلید پروژه‌ی Supabase را وارد و SQL را اجرا نکنی، به بک‌اند متصل نیست.
- Supabase Auth با ایمیل ساختگی برای username/password استفاده شده؛ قابلیت بازیابی رمز از طریق ایمیل واقعی را فراهم نمی‌کند. اگر بازیابی رمز می‌خواهی، باید طرح ورود را به ایمیل واقعی یا پیاده‌سازی امن سفارشی سمت سرور تغییر بدهیم.
- برای استفاده‌ی واقعی، رمز قوی انتخاب کن و محدودیت‌های Auth / CAPTCHA را در Supabase مطابق نیاز فعال کن.
- هیچ رمز عبوری در جدول برنامه ذخیره نمی‌شود؛ احراز هویت توسط Supabase Auth انجام می‌شود.


این نسخه برای استفادهٔ شخصی و ساده طراحی شده است. نام کاربری جدید با دامنهٔ داخلی @users.hamrahcopy.invalid ذخیره می‌شود؛ نیازی به Gmail یا تأیید ایمیل نیست. نشست کاربر به‌صورت پیش‌فرض به خاطر سپرده می‌شود.
